# Helping International Hands India (HIHI)

A simple website created for **Helping International Hands India**, a non-profit organization working towards fighting poverty, creating jobs, and supporting underprivileged communities.

## 🌐 About

This project is a static website that provides information about the organization, its activities, volunteering, donations, stories, and gallery.

## ✨ Features

* 🏠 Home
* ℹ️ About
* ⚙️ How It Works
* ❤️ Donations
* 🖼️ Gallery
* 📖 Stories of Hope
* 🤝 Volunteer
* 📞 Contact Us
* 📧 Newsletter Subscription
* 🔗 Social Media Links

## 🛠️ Technologies Used

* HTML5
* CSS3
* Font Awesome

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

That's it — no installation or server is required.
